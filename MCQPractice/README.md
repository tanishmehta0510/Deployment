# 📝 MCQ Practice

Engineering-entrance mock tests, generated by Gemini and **scored by your own code**.

Pick an exam (MHT-CET, JEE Main, JEE Advanced, BITSAT, KCET or a custom scheme), choose a subject and chapter, take the test in the browser, and get a result sheet that follows that exam's real marking scheme: negative marking, partial marking and all.

## Why this exists

Most "AI quiz" tools let the model write the questions **and** decide the marks. That breaks down fast: the model miscounts, forgets negative marking, or claims a wrong answer is right.

This app splits the job cleanly:

| The AI does | The code does |
|---|---|
| Writes the questions, options, correct answer and explanation | Decides the question-type mix per exam |
| Tags a question as a real PYQ or "PYQ-style" | Validates every question the model returns |
| | Applies marks, negative marking and partial marking |

Scoring is deterministic: the same answers always give the same marks, regardless of what the model says.

## Features

- **6 exam presets** with their own question-type mix and marking scheme (see below)
- **Syllabus-aware**: Physics, Chemistry and Mathematics chapters for Class 11 / 12 (CBSE/NCERT, ICSE, plus Maharashtra HSC-only chapters tagged `(HSC)`), and General topics for English Proficiency and Logical Reasoning
- **Three question types**: Single Correct, Multiple Correct, Numerical
- **Previous-year-question mode**: the model is asked to recall genuine PYQs (year, session, shift) and to leave fields `null` rather than invent them; anything else is labelled `PYQ-style`
- **Marking-scheme preview** before you start, including maximum marks
- **LaTeX rendering** for maths, physics and chemistry notation
- **Timed attempts**: your time is recorded when you submit
- **Detailed review**: all options shown with ✅ correct / ❌ your wrong pick, explanation per question, filter by Wrong / Skipped / Correct
- **Section-wise breakdown** by question type
- **CSV export** of your results (opens cleanly in Excel)
- **Retake the same test** with a blank answer sheet, or start a new one
- Animated UI that respects `prefers-reduced-motion`

## Supported exams

Marks live in one place, `scheme_for()` in `MCQPracticeUI.py`.

| Exam | Question mix | Correct | Wrong | Notes |
|---|---|---|---|---|
| **MHT-CET (PCM)** | Single Correct | +2 Maths, +1 Physics/Chemistry | 0 | No negative marking |
| **JEE Main** | ⅔ Single Correct, ⅓ Numerical | +4 | −1 | In the real paper you attempt 5 of 10 numericals per subject; here every numerical is evaluated |
| **JEE Advanced** | 30% Single, 40% Multiple, 30% Numerical | +3 / +4 / +4 | −1 / −2 / 0 | Multiple Correct: +1 per correct option if no wrong option is chosen, −2 if any wrong option is chosen |
| **BITSAT** | Single Correct | +3 | −1 | Subjects include English Proficiency and Logical Reasoning |
| **KCET** | Single Correct | +1 | 0 | No negative marking |
| **Custom / Board practice** | Single Correct | You set it | You set it | Choose your own correct and wrong marks |

> Exam patterns change often (JEE Advanced especially). If an official brochure differs from what's here, edit `scheme_for()` and the `EXAMS` dict.

## Quick start

**Requirements:** Python 3.10+ and a [Gemini API key](https://aistudio.google.com/apikey).

```bash
# 1. Clone and enter the project
git clone <your-repo-url>
cd <your-repo-folder>

# 2. (Recommended) create a virtual environment
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 3. Install dependencies
pip install streamlit google-genai python-dotenv pydantic

# 4. Add your API key
echo "GEMINI_API_KEY=your_key_here" > .env

# 5. Run
streamlit run MCQPracticeUI.py
```

### Configuration

Set these in a `.env` file next to the script:

| Variable | Required | Description |
|---|---|---|
| `GEMINI_API_KEY` | Yes | Your Gemini API key (`GOOGLE_API_KEY` also works) |
| `GEMINI_MODEL` | No | Model name to use. Defaults to `gemini-3.5-flash-lite`. You can also change it live from the sidebar |

⚠️ **Never commit `.env`.** Add it to `.gitignore`:

```
.env
.venv/
__pycache__/
```

## How to use

1. **Choose an exam.** The marking scheme and maximum marks update instantly.
2. **Choose subject, class and chapter** (or "All chapters (mixed)").
3. **Set test options:** number of questions (5–30), difficulty, and question source (recalled PYQs or fresh PYQ-style questions).
4. Click **Generate test 🚀**.
5. **Attempt the test.** Unattempted questions score 0.
6. **Submit** to see your score, accuracy, time taken, section-wise marks and a full review.

## How it works

```
Setup screen ──► generate_questions() ──► Test screen ──► grade() ──► Result screen
                       │
          per question type, in batches of 10:
          Gemini (JSON schema) ─► validate() ─► de-duplicate ─► keep
                       └── failed / invalid / duplicate? retry (max 3 attempts per type)
```

### Reliability measures

- **Structured output**: Gemini is called with a Pydantic `response_schema`, so the response is JSON, not free text.
- **Never trust the model's structure**: `validate()` rejects any question with the wrong type, a missing or non-finite numerical answer, anything other than exactly 4 options, out-of-range or duplicate answer indices, or a Single Correct question with more than one answer. It also strips stray `A.` / `(b)` prefixes from options.
- **De-duplication**: questions are normalised and compared, and recent questions are passed back to the model as an "avoid" list.
- **Retries with backoff**: invalid or failed batches are retried instead of silently shrinking the test. If a shortfall remains, you're told how many questions were generated.
- **HTML safety**: model-supplied text such as PYQ year and session goes through `html.escape()` before it reaches an HTML-enabled markdown block.
- **Scoring edge cases**: `nan` / `inf` are not accepted as numerical answers; numerical answers allow a tolerance of `max(0.01, 0.1% of the correct value)`.

## Customising

- **Add an exam:** add an entry to `EXAMS` (subjects, question mix, note) and a branch in `scheme_for()`.
- **Add chapters:** extend the lists in `SYLLABUS`.
- **Change batch size or retries:** edit `BATCH` and `MAX_ATTEMPTS` at the top of the file.
- **Switch model:** set `GEMINI_MODEL` in `.env` or use the sidebar field.

## Known limitations

- **PYQs are recalled by the AI from memory.** It can misremember a question, its year or its answer. Questions tagged `PYQ` show what the model *believes*; verify important ones against the official paper.
- **AI-written answers can be wrong.** The app guarantees the *scoring* is correct for the stored answer key, not that the key itself is correct. Treat the explanations as a study aid, not ground truth.
- **JEE Main numericals:** all numerical questions are evaluated; the real exam's "attempt any 5 of 10" choice is not modelled.
- **No persistence:** tests and scores live in the Streamlit session. Use the CSV export to keep a record.
- Exam patterns are hard-coded and may need updating when official brochures change.
